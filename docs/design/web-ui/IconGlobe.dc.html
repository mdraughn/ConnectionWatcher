Globe

Zero learning curve. Everyone reads a globe as “the internet” and a slashed globe as “no internet”, with no legend and no onboarding.

Tradeoff. Generic — it says nothing about whose fault it is, which is the whole thesis. Rim plus two meridians is also the busiest glyph here and turns to mush below 20 px. And it fails the greyscale row: up and struggling differ only by a dashed equator, which is invisible without colour — so this direction leans on hue alone exactly where it must not.
