Layout and breakpoints
≥ 900px — full bar

Brand, both nav groups split by a hairline, then the verdict pip, theme and admin-mode buttons. Content centres at 1250px with 26px gutters.

< 900px — drawer

Nav collapses to a hamburger; the verdict pip stays in the bar, because knowing the verdict is why the page is open. Gutters drop to 16px, rows grow to 44px, tables restack as cards.

Wayfinding

Every page opens with a title and one sentence saying what it is for. Sections are named by a hairline rule, never a bare heading. The active page is marked in the bar and the drawer.
